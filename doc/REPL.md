# REPL
## командный интерфейс

- `send` запускается как подчинённое консольное приложение
  - получает команды управления через `stdin`
  - возвращает результаты исполнения команд через `stdout`
  - также в `stdout` выводится результат работы фоновых операций
- опционально в командной строке можно передать 1+ текстовый файл
  - скрипт с набором команд инициализации

## команды

### `exit`
- завершить работу

### `repl`
- запустить интерактивную консоль для ввода/выполнения команд
- нужно указать в конце скрипта инициализации

### `list`
- список сетевых интерфейсов, доступных через DPDK (отвязнные сетевые карты)
