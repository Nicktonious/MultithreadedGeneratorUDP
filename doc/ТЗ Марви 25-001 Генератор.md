## Предмет ТЗ
## Назначение 

Генератор предназначен для создания условий (среды и сигналов) для отладки [[MRP-S Server|ПО сбора и обработки данных]] с датчиков измерительной установки ООО "Марви" в условиях физического отсутствия датчиков и аппаратной платформы установки

## Функционал 

1. Генерация UDP пакетов, отправка их по сети Ethernet и приемка на сетевом порту аппаратной платформы  

2. Возможность генерации пакетов 
	- по каждому файлу из заданного набора входных файлов 
	- с последовательными кадрами согласованного формата 
		- (один кадр одного файла - один пакет),  

3. Возможность разбиения файлов на некоторое количество групп и задания для каждой группы своих характеристик отправки в качестве входных аргументов: 
    
	- Частота пакетов, Гц 
	- Время генерации, с 

4. Возможность зацикливания генерации 
	- если время генерации превышает количество кадров файла с учетом частоты, генерация продолжается начиная с первого кадра (зацикливается)  

5. При генерации, замена в каждом кадре каждого входного файла номера пакета (измерения) на генерируемый номер пакета (последовательно возрастающий, с учетом зацикливания), остальная информация в кадре – без изменений  

6. Отправка UDP пакетов 
	- одновременный **старт** последовательной **отправки** пакетов каждого входного файла с частотой, заданной для группы.
	- **Остановка отправки** по достижению времени генерации от старта. 
	- Пакеты файлов внутри группы отправляются синхронно. / 
	- одновременность старта и синхронность – с точностью до периода 

7. Обеспечение для каждой группы заданной частоты отправки и приемки (на АП) UDP пакетов независимо для каждого файла
