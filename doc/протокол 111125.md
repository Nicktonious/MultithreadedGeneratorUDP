## Описание проблемы

- библиотека pcpp не поддерживает фрагментацию трафика
- удаётся вручную настроить фрагментацию с пустыми UDP-пакетами
    - UDP-заголовок с нулевой длиной данных только в 1м фрагменте
    - все фреймы кроме последнего отправляются с установленным флагом [[MF]]
    - все фреймы имеют установленное полe [[offset]]
- при попытке добавить payload в UDP-пакеты IP-заголовки с фрагментацией переписываются:
    - флаг MF (More Fragments) выставляется в 1 во всех фрагментах
    - offset во всех IP-заголовках обнуляется
