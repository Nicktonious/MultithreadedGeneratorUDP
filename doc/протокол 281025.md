## Текущий статус

- Реализовано:
	+ **пакетная отправка через `sendPackets()`**
	+ регулярная отправка ARP-пакетов для нотификации привязки MAC/IP адресов для отправителя и получателя (интервал 55 секунд)
	+ запуск отправки ARP-пакетов через планировщик потоков DPDK
	+ инициализация программы из `lib/send.ini` файла при старте
	+ ввод и выполнение команд через `stdin` (REPL)
	+ рестарт при изменении исполняемого или конфигурационного файла
- В работе:
	- интеграция (send) с верхним уровнем управления генератором (node.js)
		- разбор параметров командной строки
	- отправка UDP-трафика до 5 Gbit/s
- В очереди:
	- отправка сегментированных пакетов 8К
	- высокоскоростная отправка UDP-трафика

## Принятые технические решения

- **пакетная отправка через `sendPackets()`**
```cpp
class Worker : public pcpp::DpdkWorkerThread {
    virtual int data_group_size();   ///< data send group size, raw packets

int GARP::data_group_size() { return 1; }

bool Worker::run(uint32_t coreid) {
    auto dgsz = data_group_size();
    pcpp::MBufRawPacket *mbufArr[dgsz];
    for (int i = 0; i < dgsz; i++) {
        assert(mbufArr[i] = new pcpp::MBufRawPacket());
        mbufArr[i]->initFromRawPacket(_packet.getRawPacket(), _dev);
    }
    do {
        auto loop_start = std::chrono::steady_clock::now();
        _count += _dev->sendPackets(mbufArr, dgsz, 0);
    } while (!_stop && schedule());
}
```

- отправка ARP-пакетов через планировщик потоков DPDK:
	- `src/garp.cpp`
```cpp
class Worker : public pcpp::DpdkWorkerThread {
    virtual long interval();  ///< send sheduling interval, milliseconds
    virtual pcpp::CoreMask coreMask();  ///< core mask for sender's group

GARP::GARP(pcpp::DpdkDevice *dev) : Worker(dev, 55555, 0b0010, 1) {
    assert(!GARP::singleton); assert(GARP::singleton = new GARP(dev));

void Net::garp() {  //
    GARP::threads.push_back(GARP::singleton); // create single worker
    pcpp::DpdkDeviceList::getInstance().startDpdkWorkerThreads(  //
        GARP::singleton->coreMask, GARP::threads);
```

- ввод команд через `stdin` реализован как парсер на базе `flex`/`bison`
	- инициализация программы из `lib/send.ini` файла при старте
		- .ini файл передаётся в командной строке первым параметром
	- цикл ввода команд: `src/repl.cpp`
		- запускается после обработки .ini файла
		- выполняет ввод команд через stdin используя библиотеку `libreadline`
		- вводит приглашение для ввода команд, и хранит историю: `bin/send` может быть запущен как самостоятельное консольное приложение, и принимать команды в интерактивном ручном режиме от пользователя
- лексер: `src/send.lex`
	- распознает группы отдельных символов как типизованные токены
	- содержит фрагмент С++ кода относящийся к лексеру:

```cpp
/// current file name
char *yyfile = nullptr;

/// parse (and run) string as a command ( calls from REPL::repl() )
void REPL::parse(char *source) {
    YY_BUFFER_STATE buffer = yy_scan_string(source);
    yy_switch_to_buffer(buffer);
    yyparse();
    yy_delete_buffer(buffer);
}
```

- парсер `src/send.yacc`
	- содержит описание грамматики доступных команд и синтаксических элементов

```bison
syntax: | syntax expr | syntax config | syntax net | syntax repl

expr    : _INT          { std::cerr << "int:" <<  $1 << "\n"; }
        | _NUM          { std::cerr << "num:" <<  $1 << "\n"; }
        | _STR          { std::cerr << "str:" << *$1 << "\n"; }
        | _ID           { std::cerr <<  "id:" << *$1 << "\n"; }

config  : _MAC          { std::cerr << "mac:" << *$1 << "\n"; }
        | _IP           { std::cerr <<  "ip:" << *$1 << "\n"; }

net     : _LIST         { Net::list();      } // `list` available DPDK NIC's
        | _OPEN _INT    { Net::open($2);    } // `open <nic>`
        | _GARP         { Net::garp();      } // `garp` run GARP sender

repl    : _REPL         { REPL::repl();     } // `repl` run REPL from .ini
        | _EXIT         { REPL::exit();     } // `exit` exit send'er
```

- завершение с кодом `errorlevel =1` если бинарный или .ini файл был изменён
	- позволяет автоматизировать рестарт сервиса в процессе разработки
		- при перекомпиляции по изменению исполняемого файла
		- `mk/all.mk`: `sudo make watch`
```Makefile
watch: bin/$(BINFILE) $(S)
	@$^ ; while [ $$? -eq 1 ]; do $^ ; done
```
